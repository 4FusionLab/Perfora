# История изменений

[English](CHANGELOG.md)

## 1.1.0 — 2026-10-25

- Добавлены шесть полей Noise: Smooth Noise, Reaction Diffusion, Directional Fibers, Topographic, Gyroid Field и Blue Noise. Voronoi перемещён в конец Noise; в Pattern сохранены 12 повторяемых форм.
- Основные настройки шума — Cell Size и Web Thickness, с необязательной Add Bridges и дополнительными настройками полей. Сохранены старые пороги заполнения. Цвет Fast Preview по умолчанию — Magenta.
- Добавлены Along Path, Contour, Fan, Phyllotaxis, Poisson Disk, Wave, Chevron и Between Curves: всего 11 доступных семейств Distribution. Новые команды используют ревизию 2; сохранённые Features сохраняют свою ревизию и старый Running Bond.
- Поддерживаются цилиндрические, конические и регулярные гладкие грани произвольной формы твёрдых тел, а также до 32 областей одного типа поверхности в одном компоненте.
- Добавлена входящая в пакет браузерная площадка с тем же ядром геометрии Python, что и Fusion, всеми 19 формами и параметрами, которыми можно делиться.
- На всех платформах сохраняются LF и явное чтение UTF-8, чтобы байтовые хеши встроенного ядра, подписи демо и содержимое ZIP релиза оставались согласованными и в Windows.
- Ограничена дискретизация органических полей на больших областях и сохранены частичные отверстия у границы с заданным отступом.
- Исправлена зависимость Custom Feature от собственного результата: ссылки Object сохраняются через исходные грани и привязываются до поглощения геометрии булевыми операциями. Edit Feature OK обновляет старые ссылки Object.
- После завершения команды восстанавливается положение таймлайна, чтобы Cancel сохранял геометрию и состояние узла без дополнительного шага Undo. Точный предпросмотр Feature отделён от окончательного CAD-построения.
- Зафиксированная до подготовки релиза приёмка: 200 тестов Python, 36 браузерных сценариев, все шесть шумовых полей и Voronoi на копиях реальной геометрии Box, нативные Edit Feature OK/Cancel и Undo/Redo, восстановление старого узла, операции с несколькими областями, представительные криволинейные источники и локальное повторное открытие F3D.
- ZIP релиза и контрольная сумма собираются и публикуются обычным workflow GitHub Actions на трёх ОС. Локальные проверки и проверки Fusion при подготовке релиза не повторяются; нативная CAD-приёмка Windows и облачное сохранение не заявляются.

## 1.0.1 — 2026-10-24

- Исправлена потеря целевого тела Feature Cut при уменьшении исходной грани с Trim to Boundary и ненулевым Edge Offset. Точное смещение вычисляется по временным BRep-контурам без редактирования вспомогательного эскиза на грани при пересчёте.
- Добавлена регрессионная проверка в реальном Fusion для изменений высоты оболочки 70 → 20 → 70 → 20 мм с проверкой состояния вложенного Combine и видимого твёрдого тела.

## 1.0.0 — 2026-10-24

Первый стабильный выпуск Perfora. Опубликован как обычный GitHub Release с отметкой Latest.

### Узор, размещение и удобство

- Добавлены шесть цветов Fast Preview, по умолчанию Gold, и более толстые контуры; при выборе цвета повторно используется подготовленная геометрия. Подсветка выбора Fusion по-прежнему может окрашивать или перекрывать контуры.
- При первоначальном открытии команды по умолчанию выбирается Feature; последующие изменения пользователя сохраняются.
- Исправлены профили эскиза на гранях: их опорная геометрия определяется в правильной позиции таймлайна, маркер вызывающей стороны восстанавливается, а Objects выводятся из опорного тела для Cut/Intersect (и Feature Join). Split Face не требуется.

### Производительность

- Перед точными проверками зазора фильтруются близкие рёбра границы; для малых узоров сохранён прямой путь и проверка замкнутых пустот.
- Пропускается обрезка Voronoi полуплоскостью без изменений порядка соседей, Seed, очистки или условий скругления.
- Единая неизменяемая раскладка ячеек разделяется Fast Preview и финальным построением; ключ включает полные Region, разрешённые Settings и систему координат плоскости, а перед построением источник читается заново.
- Булевы операции обрезки, относящиеся только к Panel, откладываются до её запроса; кешированная панель предоставляется только после успеха всех операций.
- Источник, внутренний отступ и радиальная область кешируются раздельно; данные источника предпросмотра сбрасываются при изменении нативных ревизий тела или эскиза либо базиса плоскости.

### Параметрическое размещение

- Добавлен Spread Radius (0 = вся граница) для всех распределений с ограниченной генерацией кандидатов, точной круговой обрезкой и нативным параметром модели в новых узлах Feature.
- Выбранный центр сохраняется как зависимость Feature с пересчётом, заменой и очисткой в Edit Feature.
- Для всех распределений добавлен общий Start Point с выбором точек эскиза, вершин и конструкционных точек; он используется Fast/Full Preview и финальной геометрией.
- Помимо Fixed и Radial добавлена явная ориентация Tangential.
- Для всех 36 пустых числовых полей, включая целочисленные, восстанавливаются значения по умолчанию; явные нули, корректный заменяющий текст, выражения единиц и параметров Fusion и ошибки проверки непустых значений сохраняются.
- Неявные единицы полей нормализуются до передачи выражений в штатный Extrude; ожидающие обратные вызовы значений по умолчанию освобождаются при закрытии команды.
- Добавлено распределение Circular для 12 повторяемых форм с автоматическими концентрическими кольцами, Start Radius и ориентацией Fixed/Radial.
- Минимальная перемычка сохраняется за счёт шага по хорде и консервативных ограничивающих контуров, включая замыкающий стык кольца; сохранены точная обрезка, предпросмотр и штатные операции Extrude.
- Смещения круговой раскладки перемещают центр по осям эскиза без периодического заворачивания; Voronoi сохраняет собственное распределение.

### Документация и проверка

- Добавлены реальные скриншоты Fusion с круговой ориентацией, зоной по точке, профилями на грани без Split Face и пересчётом Feature по радиусу.
- Опубликованы воспроизводимые сценарии и результаты измерений с разделением генерации на чистом Python и предпросмотра/построения в Fusion.
- Сохранены стабильные ID команды, UUID манифеста, атрибуты документа и лицензия GPL-3.0-only этого выпуска.
- Нативная CAD-приёмка зафиксирована для Fusion 2706.1.14 на macOS 27.0.1. CI Windows охватывает Python и упаковку; нативный CAD на Windows не заявлен как проверенный.

## 0.2.0 — 2026-10-23

- Voronoi как тринадцатая форма отверстий с воспроизводимыми начальными значениями, нерегулярностью, минимальной перемычкой, точной обрезкой и необязательным касательным скруглением углов.
- Экспериментальный результат Feature: параметрический узел Perfora в таймлайне с редактируемыми параметрами узора, зависимостями от исходной геометрии и пользовательским обработчиком пересчёта. Sketch и штатный Extrude остаются доступны.
- Все 13 форм, точная обрезка, скруглённые отверстия Voronoi, кешируемый Fast и транзакционный Full Preview; прямое выдавливание Distance с Join, Cut, Intersect и New Body.
- Edit Feature восстанавливает настройки узора и выражения с поддержкой Cancel и Undo/Redo. Autodesk Preview API требует работающего аддона.
- Создаваемая Fusion конфигурация `.vscode` исключена из установки и ZIP-архивов.
- Нативная приёмка Fusion на macOS: все 13 форм, пересчёт, Edit Feature, откат Full Preview, Undo/Redo и повторное открытие архива F3D. При переключении связанных копий из разных папок перезапустите Fusion; нативная CAD-приёмка Windows остаётся невыполненной.

## 0.1.5 — 2026-10-23

Первый публичный экспериментальный выпуск Perfora от 4FusionLab.

- Двенадцать форм отверстий, прямоугольное и шахматное распределение, толщина перемычек, отступы от края, независимые повороты и смещения размещения.
- Точная обрезка ячеек на границе, включая зазор вокруг внутренних отверстий.
- Профили эскиза и перфорированные панели; штатные операции Extrude Join, Cut, Intersect, New Body и New Component.
- Кешируемый предпросмотр контуров и необязательный полный CAD-предпросмотр.
- Английский диалог со штатной терминологией Fusion и значками операций.
- Графика проекта, установщик macOS/Windows с резервными копиями, переносимый ZIP, контрольная сумма SHA-256 и автоматические проверки релиза.
- Стабильные ID команды и пространство имён атрибутов документа для установок, ранее называвшихся Perforator.

### Известные ограничения

Только плоская геометрия. Пользовательской параметрической операции для перестроения всего узора нет. Поведение CAD на Windows, сложные сборки, сохранение и повторное открытие документов ещё требуют приёмки. Экспериментальные сборки используйте на копиях рабочих моделей.
