# Работа над Perfora

Perfora — дополнение Autodesk Fusion от 4FusionLab для перфорации плоских областей. MVP реализован; развивай текущий инструмент, сохраняя существующие сценарии и производительность.

## Общение и документация

- Общайся с пользователем на русском. Планы, в том числе в режиме планирования, составляй на русском.
- Интерфейс дополнения, сообщения об ошибках и названия создаваемых элементов модели — на английском, в терминах Fusion: Profiles, Extrude, Join, Cut, Intersect, New Body, New Component, OK, Cancel.
- Перед изменениями прочитай соответствующий модуль и проверь рабочее дерево. Сохраняй изменения пользователя и параллельных задач.
- За актуальными возможностями и ограничениями обращайся к `README.md` и `README.ru.md`; при изменении поведения обновляй обе версии.
- Для размеров и типов отверстий используй `docs/PERFORATIONS.md`; для проверок — `CONTRIBUTING.md`; перед публикацией — `docs/PUBLISHING.md`.

## Границы MVP

- Источник: плоская грань, замкнутый профиль эскиза или конструкционная плоскость с заданной областью.
- Результат: обычные профили эскиза либо штатный Extrude с выбором операции, направления, протяжённости и целевых тел.
- Сохраняй все существующие формы и параметры раскладки. При добавлении формы обеспечь её поддержку в профилях, Fast/Full Preview, обрезке и Extrude.
- **Trim to Boundary** сохраняет частичные отверстия. **Edge Offset** остаётся активным: обрезка идёт по границе с учётом отступа, включая существующие внутренние вырезы.
- Одинаковые параметры должны давать совпадающие контуры в предпросмотре и готовой модели.
- В режимах Sketch и Extrude сетка фиксируется при создании; штатный Extrude редактируется средствами Fusion. Режим Feature создаёт параметрическую Custom Feature: сохраняй её параметры, зависимости, пересчёт и Edit Feature. Ограничения режима перечислены в обеих README.

## Архитектура

| Файл | Ответственность |
| --- | --- |
| `Perfora/geometry.py` | Независимая 2D-геометрия, формы, шаг, раскладка и зазоры; без импорта `adsk` |
| `Perfora/model.py` | Работа с источниками, эскизами, профилями и штатным Extrude |
| `Perfora/feature.py` | Параметры, зависимости, жизненный цикл и пересчёт Custom Feature |
| `Perfora/solid.py` | Точное временное тело прямого выдавливания без создания узлов таймлайна |
| `Perfora/clipping.py` | Точная обрезка временными BRep-операциями и смещение границы |
| `Perfora/preview.py` | Кэш раскладки, система координат и пакетная графика Fast Preview |
| `Perfora/Perfora.py` | Команда, диалог, обработчики событий и жизненный цикл сессии |
| `Perfora/ui_resources.py` | Поиск нативных значков в текущей установке Fusion с запасным текстовым представлением |
| `PerforaSmokeTest/` | Проверки внутри настоящего Fusion |
| `install.py` | Локальная установка с резервной копией и сборка ZIP |

- Геометрическое ядро использует внутренние единицы Fusion: сантиметры. Преобразования единиц и пользовательские выражения обрабатывай явно на границе с API.
- Дополнение работает на Python, поставляемом Fusion, без сторонних зависимостей времени выполнения.
- Сохраняй совместимость: command ID `DiegoV_Perforator`, UUID из manifest и пространство атрибутов `DiegoV.Perforator` намеренно оставлены после переименования. Их изменение требует продуманной миграции.
- Версию бери из `Perfora/Perfora.manifest`. Сохраняй лицензию GPL-3.0-only и существующие SPDX-заголовки.

## Fusion API и интерфейс

- Для вопросов о SDK/API, его синтаксиса, настройки и специфичных для API ошибок используй Context7: сначала `resolve-library-id`, затем `query-docs` по выбранному ID и конкретному вопросу. Если документация Fusion отсутствует или неполна, проверь официальную документацию Autodesk и определения API установленного Fusion. Отмечай непроверенные предположения.
- Для чистого рефакторинга, алгоритмов геометрии и редактирования документации запрос к Context7 не требуется.
- Строй диалог на нативных CommandInputs. Сравнивай изменения с настоящими Extrude и Pattern: подписи, пиктограммы, группировка, видимость полей и кнопки подтверждения.
- Нативную графику разрешай через `ui_resources.py` из текущей установки; сохраняй текстовый fallback. Ресурсы Autodesk в дистрибутив не копируй.
- `CommandInput.name` доступно только для чтения: для меняющихся подписей используй существующие связанные поля с переключением видимости и синхронизацией выражений.
- Не переноси сворачивание вложенных групп без проверки в Fusion: оно уже вызывало ошибку `the group cannot be folded`.
- Храни ссылки на обработчики событий до завершения сессии. Учитывай исчезновение выбранной сущности при отмене команды и освобождай временные ресурсы.

## Производительность и геометрия

- **Единое ядро:** Fusion и веб-демо исполняют одни исходники геометрии Perfora для всех форм и Distribution. Браузерный слой отвечает за ввод и отображение; алгоритмы раскладки и проверки зазоров остаются в Python-ядре. Образцы и миниатюры также генерируй этим ядром. Веб-версия предназначена для быстрой проверки, экспорт ей не требуется.
- **Быстрая визуальная проверка:** веб-демо — штатный стенд перед CAD-приёмкой. При изменении паттерна пересобери демо и проверь соответствие браузерного результата общему ядру: параметры, координаты/контуры, зазоры, seed и ревизия алгоритма. Порядок сборки и проверки — в `demo/README.md`. Проверка веб-демо дополняет обязательную приёмку Fusion.

- Fast Preview использует кэш и пакетную Custom Graphics. Открытие раздела или изменение видимости поля не должно запускать полное CAD-построение.
- Инвалидируй геометрический кэш при изменении источника или параметров, влияющих на раскладку. Full Preview и окончательное построение должны учитывать актуальные параметры Extrude.
- Не добавляй атрибуты каждому ребру отверстия: это уже приводило к большим задержкам на шестигранниках из-за отслеживания сущностей Fusion. Сохраняй существующее разделение атрибутов границы и ячеек.
- Преобразование контуров в мировые координаты проверяй на смещённой и повёрнутой плоскости. Используй явный базис через `sketchToModelSpace`; замена на обратную матрицу без проверки уже приводила к смещённому превью.
- Проецируй и размечай границу до включения `sketch.isComputeDeferred`; иначе результат проекции может оказаться пустым при последующем появлении кривых.
- При обрезке сохраняй точные дуги и внутренние контуры. Проверяй минимальную перемычку и отступ с учётом допуска, поворота и частичных ячеек.

## Проверка результата

Выбирай проверки по затронутому поведению. Локальные тесты и успешная сборка ZIP не подтверждают работу CAD или интерфейса Fusion.

```sh
python3 -m unittest discover -s tests -v
python3 install.py --zip
```

- Изменение геометрии: локальные тесты плюс соответствующие сценарии `tests/fusion_shapes_regression.py` и `tests/fusion_clipping_regression.py` внутри Fusion.
- Изменение превью или кэша: `tests/fusion_preview_performance.py`; проверь плотную сетку шестигранников, положение контуров и отзывчивость диалога. Запиши число ячеек и измеренное время.
- Изменение команды или диалога: `tests/fusion_dialog_regression.py`, `tests/fusion_ui_contract.py` и визуальная проверка. Проверь переключение затронутых режимов, настоящий OK и Cancel без остаточной геометрии.
- Установка или упаковка: собери ZIP, проверь состав и установку в отдельный временный `--api-root`, включая резервную копию при повторной установке.
- Изменение иконки: сохрани оригинал пользователя и прозрачность, подготовь размеры 16/32/64. Fusion кэширует ресурсы; при необходимости используй новый каталог и перезапусти только дополнение. Проверь кнопку на настоящей панели.
- Перед выпуском выполни приёмку из `CONTRIBUTING.md`, включая Undo/Redo, сохранение и повторное открытие, редактирование штатного Extrude. Указывай фактическую версию Fusion и ОС; результаты macOS не подтверждают Windows.
- В отчёте различай локальную проверку, проверку установленной копии и наблюдение в интерфейсе. Исторические отчёты не считай проверкой текущей сборки.

## Работа с приложениями пользователя

- Для CAD-проверок по умолчанию создавай отдельный несохранённый документ. Текущий пользовательский документ используй, когда это разрешено задачей; сохраняй его геометрию и не сохраняй файл без запроса.
- Проверяй, какая копия дополнения действительно загружена. Установка файлов сама по себе не обновляет исполняемый модуль и кэш значков.
- Для работы с Fusion, браузером и другими приложениями сначала используй доступные MCP-инструменты. Переходи к Computer Use только тогда, когда возможностей MCP недостаточно для нужного действия или проверки. После действий проверяй фактический результат; состояние переключателя само по себе не доказывает запуск дополнения.
- При зависшем расчёте сначала пробуй штатную отмену. Принудительное завершение и перезапуск Fusion с пользовательскими документами требуют отдельного согласования.
- Для сайтов предпочитай подключённый DevTools или конкретную вкладку с узкими запросами. Проверяй реальное подключение; для визуальной проверки используй скриншоты. Не включай удалённую отладку и не перезапускай браузер только ради экономии токенов без согласования.

- Используй Conventional Commits; для новой ветки по умолчанию — префикс `codex/`.

- Не включай в коммиты и дистрибутив кэши, локальные отчёты, секреты и резервные копии установок. Упаковку выполняй штатным `install.py`.
