# Perfora for Autodesk Fusion

<img src="perfora.png" alt="Perfora" width="240">

**Goddess of holes. Precision for Fusion.**

Perfora is a 4FusionLab add-in for creating hole patterns and perforated panels in Autodesk Fusion.

[Русский](README.ru.md)

## The legend

Every good workshop needs a patron deity. Ours is Perfora: goddess of holes, guardian of clean edges, and sworn enemy of drilling the same pattern by hand.

She belongs to 4FusionLab's own mythology, with a playful nod to ancient Greece.

## What Perfora does

- **12 hole shapes:** circle, hexagon, square, slot, triangle, rectangle, diamond, ellipse, pentagon, octagon, cross, and star.
- Rectangular and staggered patterns, with adjustable web thickness, edge offset, rotation, and placement.
- Optional trimming of holes to the selected boundary.
- Hole profiles or perforated panels from planar faces, closed sketch profiles, and construction planes.
- Sketch output or native Fusion Extrude operations: **Join, Cut, Intersect, New Body, and New Component**.
- Fast contour previews and a full CAD preview.

Designed for ventilation panels, grilles, enclosures, and 3D-printing projects.

## Availability

**In development. This repository currently contains project information, artwork, and licensing only.**

The add-in source code, installer, test suite, and distribution packages have not been published. There is no public download or installation procedure yet.

The working build is experimental. Windows CAD behavior and final release acceptance still need verification. Perfora currently targets planar geometry; it does not regenerate an entire hole pattern through a custom parametric feature.
