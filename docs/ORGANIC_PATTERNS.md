# Органические паттерны Perfora

Perfora 1.1.0 объединяет шесть шумовых полей и Voronoi в разделе Noise. Прежние идентификаторы форм, command ID, manifest UUID, атрибуты и схемы Feature 1/2 сохранены.

## Формы и алгоритмы

| Field | Поле и характер рисунка | Основные поля |
| --- | --- | --- |
| Smooth Noise | Двумерный градиентный шум с квинтической интерполяцией и дополнительной октавой; нерегулярные округлые отверстия | Cell Size, Pattern Angle, Seed |
| Reaction Diffusion | Настоящая итерационная реакция–диффузия Gray–Scott; коралловые и лабиринтные прорези | Cell Size, Pattern Angle, Seed |
| Directional Fibers | Анизотропный градиентный шум с плавным искривлением; вытянутые прорези с поперечными мостиками | Cell Size, Pattern Angle, Seed |
| Ridged Noise / Topographic | Периодические уровни низкочастотного рельефа с модулем шума; вложенные дуги и полосы, соединённые материалом | Cell Size, Pattern Angle, Seed |
| Gyroid Field | Сечение поля `sin(x)cos(y) + sin(y)cos(z) + sin(z)cos(x)` плоскостью с нормалью (1,1,1), с фазой, определяемой Seed | Cell Size, Pattern Angle, Seed |
| Blue Noise / Size Gradient | Воспроизводимая упаковка кругов переменного радиуса с проверкой суммы обоих радиусов и Web Thickness | Maximum Diameter, Size Variation, Size Gradient, Direction, Seed |

Gyroid Field создаёт плоские контуры для прямых инструментов. Это не объёмная TPMS-решётка. Blue Noise дополняет существующий Poisson Disk: тот сохраняет одинаковую форму и размер, а новый режим меняет радиусы. Спектральная оптимизация синего шума не заявляется.

Gray–Scott рассчитывается на периодической сетке 128×128: 1000 шагов, dt=1, Du=1, Dv=0.5, feed=0.04, kill=0.06. Девятиточечный лапласиан использует веса −1 в центре, 0.2 по сторонам и 0.05 по диагоналям. Seed задаёт начальные возмущения. Неизменяемые поля последних трёх Seed кэшируются; это ограниченный кэш чисел без объектов Fusion. Базовый период решателя составляет 128/12 Cell Size. Плавное непериодическое искривление координат убирает буквальное повторение плитки; на большой области сходные мотивы всё ещё могут быть узнаваемы. Изменение масштаба, порога или направления использует уже рассчитанное поле того же Seed.

Алгоритмические ориентиры: [градиентный шум Ken Perlin](https://cs.nyu.edu/~perlin/noise/) и [модель Gray–Scott в изложении Karl Sims](https://www.karlsims.com/rd.html). Реализация самостоятельная, на стандартном Python, без сторонних зависимостей выполнения.

## Значение полей

**Add Bridges** — отдельная галочка, по умолчанию выключенная. Она добавляет локальные поперечные связи в длинных прорезях; без неё сохраняется естественный рисунок поля. Обязательная защита связности материала и Web Thickness остаются активными. Галочка скрыта для Blue Noise, сохраняется в Feature, восстанавливается в Edit Feature и при открытии F3D.

Cell Size — физический масштаб поля в единицах длины, а не одинаковая ширина каждого отверстия. Web Thickness задаёт минимальную перемычку. Внутренний порог поля выбирается по форме; прежний Field Fill сохраняется только для совместимости существующих Feature. Утолщение перемычек, мостики, скругление концов, отступ и обрезка уменьшают итоговую открытую площадь.

Для Blue Noise Maximum Diameter — наибольший диаметр. Size Variation 65% разрешает диаметры от 35% до 100% этого значения; при 0% размеры одинаковые. Size Gradient от −100% до +100% задаёт направленное изменение размера: 0% — случайные размеры, +100% — увеличение вдоль Direction, −100% — обратное направление. Значения между ними смешивают градиент и случайную вариацию.

Pattern Angle поворачивает весь мотив; Seed / New Pattern воспроизводимы при одинаковом источнике и настройках. Distribution и Hole Angle скрыты: эти формы определяют собственное поле и не совмещаются с Circular, Along Path или восемью дополнительными Distribution. Переключение обратно на повторяемую форму восстанавливает выбранную раскладку. Вызов через API с несовместимым сочетанием отклоняется явно, без подмены алгоритма.

Start Point и X/Y Offset сохраняют фазу поля в его осях. Для нескольких плоских областей используются общие оси компонента и начало, как в общей команде. Порог, топология мостиков и конечная упаковка разрешаются отдельно в окне каждой области; соседние окна не являются вырезками одной бесконечной готовой сетки. Изменение габаритов источника может изменить отверстия и их количество. Перекрывающиеся области запрещены.

## Перемычки, контуры и стоимость

Материал на сетке соединяется минимальным остовным лесом кратчайших растровых путей. При включённой Add Bridges длинные прорези дополнительно делятся мостиками; поперечные разрезы не накладывают на всю панель одну регулярную решётку. Затем евклидово расстояние утолщает материал с запасом на диагонали сетки и аппроксимацию. Ограниченное знаковое поле расстояния сглаживается, скругляя концы и убирая игольчатые выступы. Мостик пересекает только одну локальную ветвь прорези, а не весь ряд отверстий. Контуры равномерно пересэмплируются и адаптивно аппроксимируются кубическими кривыми с согласованными касательными. В Fusion это точные кубические NURBS; одни и те же кривые поступают в Fast Preview, обрезку, Sketch и прямое выдавливание.

Проверяются замкнутость, самопересечения и расстояние между готовыми контурами. При распаде узкой прорези на несколько отверстий новые перемычки проверяются отдельно: узкая связка локально утолщается с повторным выделением контуров. Только остаточные конфликтующие мелкие фрагменты после ограниченного числа уточнений пропускаются. Описанные габариты не заменяют эту плоскую проверку. Целые отверстия учитывают внешний край и внутренние вырезы; их отбор консервативен в пределах допуска дискретизации кривой. Trim to Boundary сохраняет безопасные частичные отверстия с действующим точным Edge Offset. При выборе органической формы в новой команде обрезка включается автоматически; возврат к повторяемой форме восстанавливает прежний переключатель. Сохранённые Feature не переопределяются этим начальным поведением.

При Edge Offset около нуля точная проверка материала отклоняет локальный фрагмент отверстия, который создавал бы отдельный островок: он остаётся материалом. Положительный отступ не увеличивается скрыто до Web Thickness. Соединённость — геометрическая защита, не расчёт прочности, усталости или технологичности изготовления.

Шаг дискретизации — Cell Size / 16 для ранее допустимых областей; на больших областях он адаптируется до Cell Size / 8, сохраняя лимит узлов и физический масштаб поля; допуск аппроксимации кривых — 0.22 шага. Детали меньше разрешения могут исчезнуть. Бюджет поля — 120000 узлов с защитным ореолом; бюджет принятых контуров — 16000 рёбер, плюс ограниченный предварительный бюджет. Maximum Holes остаётся 1–5000 и считается суммарно для нескольких областей. Слишком плотный запрос завершается понятной ошибкой с предложением увеличить масштаб или уменьшить область. Время CAD зависит и от числа рёбер, сложности границы и кривизны.

## Поверхности и результат

| Источник | Размещение и ограничения |
| --- | --- |
| Плоская грань, плоский профиль, Construction Plane | Все шесть полей в физических координатах плоскости; точная обрезка с внутренними контурами |
| Цилиндр | Карта окружность/ось; центры переносятся периодически, дубли шва удаляются; конечные инструменты разделяются по глубине |
| Конус | Центры адаптируются к местной окружности; инструменты сохраняют размер; участки у оси/вершины и слишком длинные для Distance пропускаются локально |
| Freeform | Физическая карта существующего адаптера, локальные нормали и та же точная маска; сингулярности и непригодные локальные участки не исключают остальную грань |

На кривой грани Direction 0° соответствует окружной/первой оси карты, 90° — оси цилиндра, меридиану конуса или второй оси карты freeform. Волокна можно направлять вдоль или поперёк оси. Разделяющие плоскости могут укорачивать органические контуры и делать рисунок более редким на сильной кривизне. На шве обеспечивается перемычка, а не непрерывное продолжение случайного поля через произвольную длину окружности. Это прямые конечные инструменты, не геодезические прорези и не оборачивание плоского эскиза по поверхности.

Слишком длинные для локальной проекции прорези пропускаются. Если после этого не осталось отверстий, построение или пересчёт завершается ошибкой. Уменьшите Cell Size, включите Add Bridges либо увеличьте Distance в допустимых пределах.

Sketch создаёт фиксированные контуры; на кривых — существующий путь 3D-контуров. Extrude создаёт фиксированный штатный Extrude на плоскости либо Base Feature/Combine на кривой. Feature сохраняет настройки и нативные параметры, зависимости, Edit Feature и пересчёт. Ограничения Distance/нулевого Taper/операций и неизменяемых источников/Objects остаются прежними. Новые поля старых узлов получают значения по умолчанию; если узел создан до появления этих нативных параметров, редактируемые числовые значения сохраняются в снимке. Для новых зависимостей выражений пересоздайте Feature.

Выбор до 32 областей остаётся однородным по типу поверхности. Плоскость, цилиндр, конус и freeform не смешиваются. Между кривыми областями действует существующая консервативная проверка конечных инструментов.

## Проверки

Текущая проверка интерфейса 2026-10-25: разделы Pattern/Noise, все 19 форм,
Voronoi последним в Noise и Magenta по умолчанию проверены в загруженной
копии Fusion 2706.1.14 на macOS. В браузере прошли 36 сценариев, включая
переключение разделов с восстановлением настроек и мобильную ширину 360 px.
Сбой пересчёта Feature исправлен: Objects сохраняются через upstream-грани,
а ссылки фиксируются до Boolean, способного удалить выбранную грань.
Таймлайн после Edit Feature восстанавливается через commandTerminated.
В загруженной копии проверены создание и изменение Cell Size всех шести
полей и Voronoi на копиях выбранной грани Box. Smooth Noise также проверен
на цилиндре, конусе и freeform; плоская Feature пересчитана после повторного
открытия локального F3D. Настоящие Edit Feature OK/Cancel, Undo/Redo всей
команды и редактирования прошли. Несколько областей проверены с Cut, Join,
Intersect и New Body. Старый узел с воспроизведённой циклической зависимостью
восстановлен и проверен изменением размера и исходной толщины.
Исходные пользовательские документы не изменялись. Это проверка macOS;
облачное сохранение и Windows CAD ей не подтверждаются.

Локальные инварианты: `python3 -m unittest discover -s tests -v`. `test_organic.py` проверяет шесть разных воспроизводимых полей, реальные зазоры контуров, граф соединения материала, евклидово расстояние, радиусы/градиент, направления/фазу, отступы/внутренние вырезы, бюджеты, кэш и версионированные параметры. `test_solid_topology.py` проверяет совпадение копий точек ядра возле границ округления; сшивание дополнительно проверяется в настоящем Fusion.

`fusion_organic_regression.py` использует реально загруженную копию: плоскость/цилиндр/конус/freeform, все шесть форм, Sketch/Extrude/Feature, Trim on/off, совпадение количества Fast/final, валидность тел и отсутствие новых lumps, изменение реального объёма при пересчёте. Опция `archive=True` экспортирует отдельные локальные F3D, открывает и пересчитывает их вновь; `capture=True` сохраняет реальные изображения.

`fusion_organic_ui.py` проверяет видимость нативных полей, Fast/Full Preview, реальные OK/Cancel, Edit Feature OK/Cancel и Undo/Redo в отдельном документе. Только успешная проверка после нажатия кнопки считается приёмкой транзакции. Временные отчёты, снимки, архивы и замеры остаются вне репозитория и ZIP. Облачное сохранение, Windows CAD и произвольные импортированные поверхности этой проверкой не подтверждаются.

В интерфейсе **Pattern Type → Noise** объединены эти шесть полей и последним **Voronoi**. Основные настройки новых шумов — Cell Size (8 mm), Web Thickness (0.8 mm), Edge Offset и Seed. Процент заполнения скрыт; прежнее значение сохраняется только для совместимости существующих Feature. Дополнительные настройки сгруппированы в Field Options. Цвет Fast Preview по умолчанию — Magenta.

`fusion_feature_dependency_regression.py` воспроизводит старую позднюю привязку BRepBody, проверяет восстановление узла и изменения исходной толщины. `fusion_selected_noise_regression.py` проверяет настоящие Feature на копиях выбранного тела: здоровое состояние, восстановление Objects и изменение объёма после изменения Cell Size.
