## Perfora's first public release

**Goddess of holes. Precision for Fusion.**

Create ventilation panels, grilles, and hole patterns directly in Autodesk Fusion.

### Highlights

- 12 hole shapes with web thickness, edge offset, rotation, and placement controls.
- Rectangular and staggered layouts; exact trimming along the boundary.
- Sketch profiles or native Join, Cut, Intersect, New Body, and New Component operations.
- Fast cached contour previews and optional full CAD previews.
- English interface, project artwork, and installation backups.

### Install without a terminal

No separate Python installation is required: Fusion includes the runtime needed by Perfora.

1. Download **Perfora-0.1.5.zip** below and extract it to a permanent location.
2. In Fusion, open **Utilities → Scripts and Add-Ins**.
3. Click **+ → Script or add-in from device** and select the inner **Perfora** folder containing `Perfora.py` and `Perfora.manifest`.
4. Select **Perfora → Run**; optionally enable **Run on Startup**.
5. Find **Perfora** under **Design → Solid → Create**, or press **S** to search.

Fusion links to the selected folder. Keep it in place; do not move or delete it after adding it.

**Optional:** if Python 3 is already installed, `python3 install.py` on macOS or `py -3 install.py` on Windows copies the add-in to Fusion's API directory and backs up previous Perfora installations. This helper is not required for the folder-linking method.

`Perfora-0.1.5.zip.sha256` contains the SHA-256 checksum. The GitHub-generated “Source code” downloads are repository snapshots; the named Perfora ZIP is the installation package.

### Experimental status

This is a **prerelease**, not a stable production build. The geometry and installer are checked by CI on macOS, Windows, and Linux; Linux is a test/build environment, not a Fusion platform. Native CAD scenarios are checked separately in Fusion on macOS. Windows CAD behavior, document save/reopen, and complex assemblies still need verification.

Output uses ordinary sketches and Extrude features. There is no custom parametric feature to reopen or regenerate the complete hole pattern. Planar faces and solid bodies only.

Upgrading from Perforator: stop and unregister the old add-in before running Perfora. Do not run both versions together.
