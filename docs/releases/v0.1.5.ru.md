## Первый публичный выпуск Perfora

[English](v0.1.5.md)

**Богиня отверстий. Точность для Fusion.**

Создавайте вентиляционные панели, решётки и узоры отверстий прямо в Autodesk Fusion.

### Основные возможности

- 12 форм отверстий с настройкой толщины перемычек, отступа от края, поворота и размещения.
- Прямоугольные и шахматные раскладки; точная обрезка по границе.
- Профили эскиза или штатные операции Join, Cut, Intersect, New Body и New Component.
- Быстрый кешируемый предпросмотр контуров и необязательный полный CAD-предпросмотр.
- Английский интерфейс, графика проекта и резервные копии при установке.

### Установка без терминала

Отдельная установка Python не требуется: Fusion включает необходимую Perfora среду выполнения.

1. Скачайте **Perfora-0.1.5.zip** и распакуйте его в постоянную папку.
2. В Fusion откройте **Utilities → Scripts and Add-Ins**.
3. Нажмите **+ → Script or add-in from device** и выберите внутреннюю папку **Perfora**, содержащую `Perfora.py` и `Perfora.manifest`.
4. Выберите **Perfora → Run**; при желании включите **Run on Startup**.
5. Найдите **Perfora** в **Design → Solid → Create** или нажмите **S** для поиска.

Fusion связывается с выбранной папкой. Сохраняйте её на месте: не перемещайте и не удаляйте после добавления.

**Необязательно:** если Python 3 уже установлен, `python3 install.py` на macOS или `py -3 install.py` на Windows скопирует аддон в каталог Fusion API и создаст резервные копии предыдущих установок Perfora. Для способа с подключением папки этот помощник не нужен.

`Perfora-0.1.5.zip.sha256` содержит контрольную сумму SHA-256. Создаваемые GitHub архивы «Source code» являются снимками репозитория; установочный пакет — именованный ZIP Perfora.

### Экспериментальный статус

Это **предварительный выпуск**, а не стабильная производственная сборка. Геометрия и установщик проверяются CI на macOS, Windows и Linux; Linux используется для тестирования и сборки, а не как платформа Fusion. Нативные CAD-сценарии отдельно проверяются в Fusion на macOS. Поведение CAD в Windows, сохранение и повторное открытие документов и сложные сборки ещё требуют проверки.

Результат использует обычные эскизы и операции Extrude. Пользовательской параметрической операции для повторного открытия или восстановления всего узора отверстий нет. Только плоские грани и твёрдые тела.

При переходе с Perforator остановите старый аддон и удалите его регистрацию до запуска Perfora. Не запускайте обе версии одновременно.
