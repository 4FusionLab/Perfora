# Perfora 1.0.1

[English](v1.0.1.md)

Исправлен пересчёт Feature Cut при уменьшении исходной грани с включённым **Trim to Boundary** и ненулевым **Edge Offset**.

## Исправления

- Изменение высоты коробки с 70 до 20 мм могло сделать целевое тело Combine внутри Perfora Feature недействительным. Родительский узел при этом мог оставаться в состоянии Healthy, хотя тело не содержало геометрии.
- Edge Offset теперь использует точные смещения временных BRep-контуров. Пересчёт больше не редактирует вспомогательный эскиз на грани и сохраняет цель булевой операции.
- Нативная регрессионная проверка Fusion охватывает повторные изменения 70 → 20 → 70 → 20 мм, состояние вложенного Combine и видимое твёрдое тело. Проверяются скруглённые и нескруглённые ячейки Voronoi, включённая и выключенная обрезка, Circle и штатные Extrude/Cut.

## Установка и обновление

Распакуйте ZIP в постоянную папку. В Fusion остановите существующий аддон Perfora, затем подключите внутреннюю папку **Perfora** через **Utilities → Scripts and Add-Ins**. Одновременно запускайте только одну копию. UUID манифеста, ID команды и атрибуты документа не изменились.

## По-русски

Исправлена потеря целевого тела у **Feature Cut** при уменьшении исходной грани с **Trim to Boundary** и ненулевым **Edge Offset**. Например, высоту коробки теперь можно менять с 70 до 20 мм и обратно с пересчётом перфорации. Исправление проверено на обычных и скруглённых отверстиях Вороного; новых функций в этом выпуске нет.
