# Perfora 1.0.1

Fix Feature Cut recompute when an upstream face shrinks with **Trim to Boundary** and a nonzero **Edge Offset**.

[Download Perfora-1.0.1.zip](https://github.com/4FusionLab/Perfora/releases/download/v1.0.1/Perfora-1.0.1.zip) · [SHA-256](https://github.com/4FusionLab/Perfora/releases/download/v1.0.1/Perfora-1.0.1.zip.sha256) · [English guide](https://github.com/4FusionLab/Perfora/blob/v1.0.1/README.md) · [Русская инструкция](https://github.com/4FusionLab/Perfora/blob/v1.0.1/README.ru.md)

## Fixed

- Changing a box height from 70 mm to 20 mm could invalidate the target body of the Combine inside a Perfora Feature. The parent node could still report Healthy while the body had no geometry.
- Edge Offset now uses exact temporary BRep wire offsets. Recompute no longer edits the face-supported scratch sketch and preserves the Boolean target.
- A native Fusion regression checks repeated 70 → 20 → 70 → 20 mm changes, nested Combine health, and the visible solid. It covers rounded/unrounded Voronoi, trimming on/off, Circle, and native Extrude/Cut.

## Install or update

Extract the ZIP to a permanent folder. In Fusion, stop the existing Perfora add-in, then load the inner **Perfora** folder through **Utilities → Scripts and Add-Ins**. Keep only one copy running. The manifest UUID, command ID, and document attributes are unchanged.

## Validation

Earlier in this development session, **67 Python tests**, **150 native CAD cases**, and the preview performance suite passed on **Fusion 2706.1.14 / macOS**. Local tests and Fusion checks were not repeated during this release preparation. GitHub Actions runs the Python and packaging checks on Linux, macOS, and Windows before publication. Native Windows CAD acceptance is not claimed.

## По-русски

Исправлена потеря целевого тела у **Feature Cut** при уменьшении исходной грани с **Trim to Boundary** и ненулевым **Edge Offset**. Например, высоту коробки теперь можно менять с 70 до 20 мм и обратно с пересчётом перфорации. Исправление проверено на обычных и скруглённых отверстиях Вороного; новых функций в этом выпуске нет.
