# Perfora 1.1.0

Noise fields, more distributions, curved faces and reliable parametric rebuilding.

## Noise and Pattern

- **Pattern** contains the 12 repeating hole shapes. **Noise** contains Smooth Noise, Reaction Diffusion, Directional Fibers, Ridged Noise / Topographic, Gyroid Field, Blue Noise / Size Gradient, and Voronoi as its last entry.
- **Cell Size**, **Web Thickness**, **Edge Offset** and **Seed / New Pattern** define the noise. Blue Noise uses Maximum Diameter; field options expose optional Add Bridges, size variation and gradient where applicable. The fill percentage is hidden; existing Features retain their saved thresholds.
- New noise commands start with 8 mm cells and a 0.8 mm web. Fast Preview defaults to **Magenta**. Large fields adapt their sampling within a fixed budget, preserving physical cell size and safe partial boundary openings.

## Placement, surfaces and multiple regions

- **11 Distribution families:** Staggered, Rectangular, Circular, Along Path, Contour, Fan, Phyllotaxis, Poisson Disk, Wave, Chevron and Between Curves. New commands use the revised shared kernel, including Follow Pattern orientation and partial boundary candidates. Saved Features retain their algorithm revision; legacy Running Bond remains editable.
- Cylindrical, conical and regular smooth freeform solid faces use the same Sketch, Extrude and Feature workflow. Distribution availability follows the source type.
- Select up to **32 regions of one surface type**, in one component, with common settings and one Maximum Holes limit. Planar faces and planar sketch profiles can be combined.
- The bundled **Pattern playground** executes the same Python geometry sources in a browser. It includes all 19 shapes, 11 Distribution families and parameter links. See the included `demo/README.md` for local use; no hosted-demo deployment is part of this release.
- Source line endings are fixed to LF and the demo builder reads UTF-8 explicitly, keeping embedded-kernel hashes, labels and packaged sources consistent on Windows as well.

## Feature recompute and editing

Object references now bind to upstream geometry before Boolean operations can consume it. This prevents a Custom Feature from depending on its own result. Edit Feature restores the correct bodies and selections, and the timeline is restored after command termination so Cancel preserves the previous model and node health.

For an existing problematic Feature, open **Edit Feature** and click **OK** once to upgrade its Object references. Existing Features remain readable. Features created before the new native path parameters must be recreated to use Along Path and its expression dependencies.

## Install or update

Extract the ZIP to a permanent folder. In Fusion, stop the existing Perfora add-in, then select the inner **Perfora** folder through **Utilities → Scripts and Add-Ins → Add-Ins → +** and run it. Keep one copy running. The installer is optional and retains a backup of an earlier installation. Manifest UUID, command ID, document attribute namespace and GPL-3.0-only licensing are unchanged.

## Recorded validation and limits

Before release preparation, **200 Python tests** and **36 browser scenarios** passed. Native acceptance used **Fusion 2706.1.14 / macOS 27.0.1 (Apple Silicon)** and included:

- Feature creation and Cell Size recompute for all six noise fields and Voronoi on copies of the selected real Box face.
- Actual Fast/Full Preview, Edit Feature OK/Cancel, creation and edit Undo/Redo, and recovery of a legacy rolled-back node.
- Multi-region Cut, Join, Intersect and New Body; changes to source-body thickness.
- Representative Smooth Noise cases on cylinder, cone and freeform sources, plus local F3D export, reopen and another parameter-driven recompute.

Local tests and Fusion checks are **not repeated during release preparation**. The existing GitHub Actions workflow builds the release commit, runs its normal Python/installation/packaging matrix on Linux, macOS and Windows, and publishes the ZIP and checksum from CI.

Performance work is bounded sampling and shared caching; no new CAD speedup ratio is claimed. Existing benchmark scripts distinguish pure-Python layout generation from source reads, preview and native construction. The real-face noise regression uses 5 mm cells, a 1.5 mm web and a 3 mm edge offset before changing Cell Size.

Native Windows CAD and cloud-save acceptance are not claimed. Custom Feature uses Autodesk's Preview API and requires Perfora to remain running. Feature supports Distance with zero taper; use native Extrude for its additional extents and New Component. Curved holes are finite straight tools, with conservative seam/curvature separation. Surface types cannot be mixed; spheres, tori and mesh bodies are unsupported. Contour uses sampled distance levels, and Between Curves requires two supported open planar guides.

## По-русски

Выпуск добавляет шесть шумов, переносит Voronoi в раздел Noise и разделяет настройки Noise/Pattern. Вместо процента заполнения используются размер ячеек и толщина перемычек; цвет Fast Preview по умолчанию — Magenta.

Доступны 11 Distribution, криволинейные грани и до 32 областей одного типа. Исправлены пересчёт Feature, восстановление Objects, Edit Feature OK/Cancel и Undo/Redo. Для старого проблемного узла достаточно один раз открыть **Edit Feature → OK**. ZIP собирается и публикуется существующим CI; локальные и CAD-проверки при подготовке релиза повторно не запускаются.
