## Parametric Perfora features and Voronoi

Perfora 0.2.0 adds a **Feature** output that regenerates the hole pattern when its parameters or upstream geometry change, and **Voronoi** as the thirteenth hole shape.

### Highlights

- **Type → Feature** creates one Perfora timeline node. Double-click it or use **Edit Feature** to change the pattern, trimming, placement, profile type, and thickness.
- Parameter expressions can reference Fusion user parameters. Recompute can change the number of holes without adding timeline nodes.
- Voronoi supports reproducible Seed/New Pattern, Irregularity 0–100%, minimum web thickness, exact boundary trimming, and optional tangent corner rounding.
- All 13 shapes support Fast/Full Preview. Feature edits support OK, Cancel, and Undo/Redo.
- Sketch and native Extrude remain available, including the broader extent and operation options of Extrude.
- Fusion-generated editor configuration is excluded from installation and ZIP packages.

### Install or update

Fusion supplies the Python runtime; no separate Python installation is required.

1. Download **Perfora-0.2.0.zip** below and extract it to a permanent location.
2. Stop the previous Perfora copy and remove its link from **Utilities → Scripts and Add-Ins**.
3. Restart Fusion before using Feature from a new folder. Switching linked copies with the same UUID in one session can retain the previous Custom Feature owner and prevent recompute.
4. Choose **+ → Script or add-in from device**, select the inner **Perfora** folder containing `Perfora.py` and `Perfora.manifest`, then click **Run**. Keep that folder in place and run one copy.
5. Find **Perfora** under **Design → Solid → Create**, or press **S** to search. Enable **Run on Startup** if you want existing Feature nodes to recompute whenever Fusion opens.

The optional `python3 install.py` (macOS) or `py -3 install.py` (Windows) installer copies the add-in into Fusion's API directory and backs up previous installations. It leaves automatic startup disabled. The adjacent **Perfora-0.2.0.zip.sha256** verifies the named installation package.

### Validation

Native acceptance: **Autodesk Fusion 2706.1.14, macOS 27.0.1, Apple Silicon**.

- 40 local geometry/installer tests; 14 native smoke scenarios; 34 shape scenarios; 35 clipping scenarios; 12 Voronoi scenarios; seven preview performance configurations.
- 45 Feature scenarios on both the worktree and an installed ZIP copy after clean Fusion launches: all 13 shapes, parameter and upstream-profile changes, supported operations and directions, user expressions, trimming, and F3D archive reopen followed by recompute.
- Real OK/Cancel in Sketch, Extrude, and Feature; Edit Feature, Full Preview rollback, Undo/Redo, and editing a native Extrude through its standard Fusion dialog.
- ZIP contents, checksum, installation, and repeat-install backups verified locally. Release CI separately checks Python and packaging on Linux, macOS, and Windows; these jobs do not establish native Windows CAD behavior.

For reference, Fast Preview generated 709 hexagons in 0.101 s and 1,138 trimmed rounded Voronoi cells in 0.663 s on the tested machine. Timings vary with hardware and model complexity.

### Experimental limits

This is an **experimental prerelease**. Use copies of working designs. Native Windows CAD behavior and complex assemblies still require acceptance testing.

Feature requires **Capture Design History** and a running Perfora add-in. It uses Autodesk's Preview Custom Feature API. This version supports straight **Distance** extents with zero taper, **One Side / Two Sides / Symmetric**, and **Join / Cut / Intersect / New Body**. Source, operation, and target bodies are fixed during edit. Use native Extrude for **All**, **To Object**, taper, or **New Component**.

Large topology changes can invalidate downstream face/edge references. Sketch and Extrude retain a fixed pattern. Planar geometry and solid bodies only.
