# Интеграция набора функций следующего релиза

Рабочая ветка: `codex/release-features`. База: Perfora 1.0.1 (`6677042`). Публикация, push, тег и новая версия manifest в этот этап не входят. Ветка предназначена и для последующих функций.

## Состав и порядок

1. Сохранена исходная реализация цилиндрических, конических и свободных поверхностей.
2. Добавлены восемь раскладок; доступность зависит от типа поверхности.
3. Подключён Along Path с выбором направляющей и параметрическими зависимостями.
4. Подключены несколько областей с единым типом поверхности, общей транзакцией и параметрическим узлом.
5. Выполняется общая локальная, CAD и UI-приёмка.

Исходные рабочие копии раскладок и Along Path не изменялись. Для интеграции их незакоммиченные результаты сохранены отдельными локальными snapshot-коммитами. Реализация нескольких областей перенесена из `ec0f649`. Все изменения собраны в текущей основной рабочей копии. Исходная ветка цилиндров остаётся доступной, её результат сохранён первым коммитом интеграции.

## Продуктовые решения

| Источник | Доступные Distribution |
| --- | --- |
| Плоскость | Staggered, Rectangular, Circular, Along Path, Contour, Fan, Phyllotaxis, Poisson Disk, Wave, Chevron, Running Bond, Between Curves |
| Цилиндр | Staggered, Rectangular, Running Bond, Poisson Disk |
| Конус | Staggered, Rectangular, Running Bond |
| Свободная поверхность | Staggered, Rectangular, Running Bond, Poisson Disk, Wave, Chevron |

Voronoi сохраняет собственную семантику и не смешивается с Distribution. Круговые/лучевые/центральные мотивы не оборачиваются в прямоугольный UV-параметр без осмысленной геометрии. Chevron и Wave доступны на свободной поверхности, но не на цилиндре и конусе. На конусе Running Bond использует местную вместимость ряда и дробный сдвиг, а не шаг самой узкой окружности.

Несколько областей: максимум 32, один компонент и один контекст экземпляра. Плоскую грань можно сочетать с плоским профилем. Цилиндры, конусы и свободные поверхности выбираются только со своим типом. Ограничение работает при preSelect и в API/пересчёте. Повторы удаляются. Construction Plane остаётся одиночным источником. Maximum Holes — суммарный предел. New Component — для одиночного источника; Intersect — по отдельному телу для каждой области.

Все источники и временные инструменты подготавливаются до первого изменения тела. Для нескольких кривых областей сохраняются локальные нормали; конфликт конечных инструментов между областями отклоняется явно, включая Voronoi. Это консервативная проверка по описанным радиусам; соседние области могут потребовать большего расстояния. Скрытого уменьшения отверстий или замены раскладки нет.

## Совместимость и скорость

- Идентификаторы команды, manifest UUID, Custom Feature Definition и атрибутов не изменены.
- Feature schema 2 сохраняет несколько источников и сопоставление Objects. Schema 1 читается старым одиночным путём.
- Живые Path/Guide сохраняются как зависимости, а не JSON-снимки. Транзитные 2D/3D выборки исключены из метаданных.
- Старые Feature без новых параметров сохраняют значения раскладок в метаданных. Для перехода старой Feature к Along Path требуется пересоздание: четыре штатных параметра пути нельзя молча потерять.
- Кэш пути дополнительно сравнивает точные данные кривой: Fusion может отложить изменение `Sketch.revisionId` до завершения события. Изменение положения точки пути должно инвалидировать кэш немедленно.
- Fast Preview повторно использует подготовку поверхности и раскладку. Изменения цвета, раскрытие групп и скрытые поля не требуют полного CAD-построения. Глубина кривого инструмента участвует в ключе: она влияет на безопасные перемычки.
- Для собственных CAD-проверок дополнение запускается штатным Script lifecycle. Загрузка entry через другой Python-скрипт может связать Custom Feature с неверным владельцем; здоровый статус узла не доказывает пересчёт. Приёмка проверяет фактический объём.

## Проверки

Используется Autodesk Fusion **2706.1.14 на macOS**. Пользовательские документы не сохраняются; сценарии создают отдельные несохранённые документы и возвращают исходный активный документ. Отчёты и изображения хранятся вне Git и ZIP, в `~/Library/Logs/Perfora/`.

Локально: 158 тестов геометрии, адаптеров, кэшей, миграции, упаковки и новых межобластных ограничений прошли. Компиляция модулей проходит. Эти тесты сами по себе не подтверждают CAD.

Начальная CAD-проверка: все восемь раскладок с круглыми отверстиями, Trim off/on и обновление живых Between Curves — 17 сценариев прошли. Выполняется расширение на остальные повторяемые формы.

Интеграционная CAD-матрица проверяет реальные Cut/объёмы, совпадение Fast Preview с количеством результата, повторный цветовой Preview, несколько цилиндрических/конических/свободных областей и изменение параметра их Feature. Отдельные сценарии покрывают Along Path, локальный F3D и нативный диалог. Итоговые результаты будут зафиксированы после завершения общей приёмки.

## Границы

Это набор функций для будущего релиза, а не выпущенная версия. Ограничения основного инструмента сохраняются: на кривых гранях конечные прямые инструменты, Distance/zero taper, отсутствие Perforated Panel; сферы, торы, mesh и участки с неустойчивой локальной параметризацией не заявлены. Сингулярные локальные участки NURBS пропускаются, когда остальная поверхность остаётся регулярной. Размер задаёт сечение прямого инструмента, а не геодезический диаметр на поверхности.

Принцип Perforate Everything реализуется адаптацией к геометрии с явной диагностикой неподдержанного случая. Он не заменяет проверку формы и не означает обещания поддержки любой топологии. Windows CAD и облачное сохранение/повторное открытие этим прогоном не подтверждены.
