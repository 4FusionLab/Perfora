## Семантика

Все восемь Distribution доступны для 12 повторяемых форм. Voronoi остаётся отдельной формой со своим распределением. Rectangular, Staggered и Circular сохранены. В новых раскладках отверстия имеют фиксированную ориентацию: Hole Angle плюс Pattern Angle, где он доступен. Radial/Tangential остаются настройками Circular.

**Web Thickness** — нижняя граница расстояния между реальными отверстиями, включая повёрнутые щели, эллипсы и невыпуклые звёзды/кресты. Новые генераторы используют описанные окружности и пространственный индекс соседних центров. У вытянутых форм упаковка намеренно консервативна. Близкие кандидаты, в том числе у вершины, центра веера, на соседних рядах и при замыкании контура, пропускаются. Это не алгоритм максимально плотного заполнения; регулярный ряд может содержать пропуски.

**Along Spacing / Row Spacing** задаются в единицах длины; 0 выбирает автоматический шаг `описанный диаметр + Web Thickness`. Меньший положительный шаг повышается до этого минимума. Автоматический Along Spacing Wave учитывает разницу длины дуги и хорды при ограниченной кривизне. Для автоматического Row Spacing Wave дополнительно учитывает наклон и фазовый сдвиг соседних рядов, Chevron — нормальное расстояние между плечами, Contour — запас на дискретизацию поля. Явно заданный шаг сохраняет общий контроль близких кандидатов. Row Spacing не используется в Phyllotaxis, Poisson Disk, Fan и Between Curves. Поля показываются только в соответствующей раскладке.

| Distribution | Настройки и поведение |
| --- | --- |
| Contour | Последовательные уровни внутреннего расстояния до внешней границы и вырезов. Первый уровень: Edge Offset + описанный радиус + допуск границы; следующие — через Row Spacing (при 0 — автоматический шаг с запасом на допуск). Along Spacing отсчитывается по длине каждого замкнутого ряда. Поле расстояния допускает разделение и исчезновение компонентов, не смещает вершины многоугольника независимо. Дубли замыкания исключены. |
| Fan | Start Point или автоматический центр; Sector Angle против часовой стрелки от Pattern Angle, Ray Count либо положительный Angular Step. Последняя граница неполного сектора включается, даже если последний угол меньше шага. При 360° последнего дублирующего луча нет. Along Spacing идёт от Start Radius вдоль каждого луча. Общий индекс пропускает слипающиеся отверстия у центра. |
| Phyllotaxis | Золотой угол `π(3−√5)`, радиусы пропорциональны `√(номер + 1/2)` (спираль Vogel без скученного центра). Density Ratio 0.05–4 меняет плотность кандидатов; Spread Radius ограничивает область. Фильтр перемычек может удалять кандидаты: увеличение Density Ratio не обещает строго монотонного числа отверстий. Случайного состояния нет. |
| Poisson Disk | Bridson-подобный случайный рост с активным списком и 30 пробами в кольце для каждой активной точки. Минимальное расстояние не меньше автоматического шага; Along Spacing может увеличить его. Seed воспроизводит поле при тех же границах, настройках и Python; New Pattern увеличивает Seed. Поле генерируется в ограниченном прямоугольном охвате, затем отбирается по области. Это не Voronoi и не гарантия насыщенности/максимального числа отверстий. |
| Wave | Синусоидальные ряды; Amplitude, Wavelength, Phase и Row Phase. Шаг измеряется по длине полилинейного приближения синусоиды, с ограничением производной при дискретизации; не по X. Последние интервалы равномерно распределены по длине, затем применяется контроль хорды/перемычки. |
| Chevron | Повторяющиеся V-ряды, Chevron Angle 0–90° без крайних значений. Along Spacing идёт по каждому плечу; вершина добавляется один раз. Row Spacing измеряется по оси Y раскладки. У вершины и соседних рядов действует общий контроль перемычек. |
| Running Bond | Регулярные ряды с накопительным сдвигом `row × Row Shift Ratio` по модулю шага. Поддерживаются `1 / 3`, `1 / 4`, `1 / 2` и другие отношения 0–1; это отдельная раскладка, не замена Staggered/Rectangular. |
| Between Curves | Две открытые направляющие, Row Count 2–200, Along Spacing. Соответствие по нормированной накопленной длине обеих кривых; направление Guide 2 автоматически выбирается по концам, Reverse Guide 2 меняет его относительно автоматического решения. Промежуточные ряды — линейная интерполяция соответствующих точек, затем равномерная выборка по длине каждого ряда. Число отверстий в разных рядах может отличаться. |

### Привязки, обрезка и допуски

В Fan, Phyllotaxis, Poisson Disk, Wave, Chevron и Running Bond Start Point и X/Y Offset задают начало в осях Pattern Angle. Новые смещения абсолютные, не периодические. Seed не фиксирует Poisson Disk в мировых координатах при изменении границы или охвата поля.

Contour привязан к исходной границе, Between Curves — к направляющим. Pattern Angle скрыт для этих режимов; Hole Angle задаёт ориентацию отверстий в осях Profiles. Start Point/X/Y Offset появляются только при положительном Spread Radius и двигают **зону ограничения**, а не исходные контуры/направляющие. Spread Radius 0 убирает зону. Геометрическое ядро также принимает Pattern Angle для поворота отверстий при программном вызове; оно не поворачивает сами направляющие или контуры.

Whole/Trim используют одно поле кандидатов и одинаковый порядок проверки перемычек: включение Trim не удаляет ранее допустимые целые отверстия. Edge Offset и внутренние вырезы обрабатываются существующими точными BRep-путями; обрезка не увеличивает отверстие и потому не уменьшает перемычку. Contour строит ряды внутри границы и не обязан создавать частичные отверстия на прямом внешнем ребре. В Perforated Panel материал вне Spread Radius сохраняется.

**Contour не является точным CAD-offset.** Signed-distance поле строится на треугольной сетке с диагональю ячейки не больше Contour Tolerance (по умолчанию 0.2 mm), также не больше доли шага рядов. Это разрешение поля, не обещание точности BRep или топологии ниже этого масштаба. Узкие детали ниже разрешения могут исчезнуть; при неоднозначном графе уровня расчёт завершается явной ошибкой. Для тонких шеек уменьшайте допуск в пределах бюджета. Отбор целых отверстий дополнительно проверяет исходную границу; финальная обрезка использует точную геометрию Fusion. Бюджет поля — 180 000 узлов, прохода строк/сегментов — 12 млн; превышение требует увеличить Contour Tolerance или упростить границу.

**Between Curves: поддерживаемый контракт.** Один SketchCurve или один BRepEdge на каждый выбор; обе направляющие должны быть открытыми, плоскими на Profiles и в том же компоненте. Cross-component направляющие, цепочки кривых, замкнутые направляющие, самопересечения, касание/пересечение направляющих, схлопывающиеся и складывающиеся полосы не поддерживаются. Проверки работают по strokes с допуском 0.001 mm и допуском плоскостности 0.005 mm; максимум 2048 stroke-точек на направляющую. Добавляются общие вершины долей длины и регулярная сетка соответствия. Это ограниченная проверка полилинейной полосы, не доказательство корректности произвольных сложных сплайнов. Неподдержанный случай даёт английскую ошибку, не fallback на grid.

Общий бюджет — 100 000 кандидатов, результат — прежний Maximum Holes до 5000. Слишком плотные сетки и удалённые начала отклоняются до CAD-построения. Ограничения времени не означают гарантированной отзывчивости Fusion: нативная приёмка ещё не выполнена.

## Интеграция и хранение

- `geometry.Settings`: дополнительные поля с безопасными значениями по умолчанию; старый `layout='grid'` и `staggered` читаются без миграции документов. `generate` направляет новые ID в `distributions.py`.
- `distributions.py`: реестр полей/активных параметров, генераторы, индекс центров, BVH для ближайших рёбер Contour. Нет `adsk` и внешних зависимостей.
- `curves.py`: `ArcPath(points)` → `at(normalized_length)`, `spaced(cm)`; `prepare_guides(first, second, tolerance, reverse)` → два ArcPath и общие доли длины. Это точка объединения с будущей Along Curve; не добавляйте второй контракт полилинии в параллельной ветке.
- `model.guide_reference`: проверка компонента/контекста и объект зависимости; `model.guide_strokes(entity, frame, component)` → immutable tuple 2D-точек. SketchCurve.geometry преобразуется через **native parentSketch.sketchToModelSpace**; BRepEdge.evaluator сохраняет trimmed extents. Тот же явный базис используется для всех путей. Нет неявного проецирования неплоской направляющей.
- `model.layout_settings`: единое разрешение точки и актуальных stroke-координат до вызова `GeometryCache`. Fast Preview, Sketch/Extrude и Feature используют этот адаптер. Изменившиеся strokes меняют Settings и ключ кэша, даже при сохранении сущности направляющей. BRep-тела не попадают в геометрический кэш.
- `feature.py`: новые параметры видны в Fusion Parameters у **новых** Feature; направляющие сохраняются как зависимости `guide1`/`guide2`, не как живые объекты в JSON. Edit Feature восстанавливает Distribution, параметры, Reverse Guide 2 и выбор направляющих; потерянная направляющая допускает открытие редактора для замены, но не пересчёт с молчаливой заменой.
- Схема JSON остаётся 1, новые поля опциональны. В старых Feature отсутствующие новые параметры берутся из Settings/значений по умолчанию. При Edit Feature новые числовые значения старого узла сохраняются в JSON; новые строки в Fusion Parameters автоматически не добавляются. Выражения новых полей у старого узла таким способом не становятся зависимостями: для параметрических выражений пересоздайте Feature.
- Геометрические и булевы пути `clipping.py`, `solid.py`, Full Preview и операции Extents не продублированы и не расширены сверх прежних ограничений Feature. Все дополнительные длины — cm, углы — rad. Строки интерфейса — английские; ресурсы Autodesk не копируются.

Контекст API проверен через Context7 (`/ipendle/autodesk-fusion-api-documentation`, стороннее зеркало) и **статические** определения установленного Fusion: `CurveEvaluator3D.getParameterExtents/getStrokes`, `SketchLine.geometry/worldGeometry`, `Sketch.sketchToModelSpace`, `CustomFeatureInput.addDependency`, `SketchPoint.move`. Официальные страницы Autodesk из инструмента чтения не загрузились. Определения находятся в `Autodesk Fusion 360/API/Python/defs/adsk/{core,fusion}.py`. Чтение файлов не запускало Fusion; наблюдений работы API нет.

## Локальная проверка

```sh
python3 -m unittest discover -s tests -v
python3 scripts/benchmark_layout_variants.py --repeat 3
python3 -m compileall -q Perfora tests
python3 install.py --zip
```

`test_layout_variants.py` проверяет все 8 × 12 комбинаций, реальные повёрнутые контуры, описанные габариты/перемычки, замыкания, центр веера, фазу Wave, Running Bond 1/3 и 1/4, золотой угол, Seed, смещения, внутренние вырезы, разветвляющийся Contour, ошибки направляющих, плотность и invalidation кэша. `test_layout_contracts.py` исполняет реальные тела методов UI/адаптера/Feature против узких офлайн-двойников без импорта `adsk`; проверяет миграцию, управление зависимостями, выбор режима, видимость и скрытые ошибочные поля. Это не проверка нативных событий, UI или транзакций.

ZIP носит версию из неизменённого manifest **1.0.1**, но содержит неопубликованную рабочую ветку. Не путать с опубликованным архивом 1.0.1. Сборка не устанавливает дополнение.
